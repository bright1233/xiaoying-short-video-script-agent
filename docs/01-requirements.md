# 需求与成功标准

## 用户与目标

创作者输入主题、受众、平台、目标时长、风格，得到可编辑且有产品事实来源的短视频脚本。

## 范围

本项目提供 FastAPI HTTP 接口、LangGraph Agent、合成产品素材、时长估算与品牌规则检查。输出标题、分镜、旁白或字幕、估计总时长、素材 ID、风险及任务状态。不生成视频，不连接真实发布系统，不开发前端。

## 状态

- `completed`：当前脚本版本通过时长与规则检查。
- `needs_input`：缺少必需的业务输入或素材事实。
- `incomplete`：达到步数上限或仍有未解决的时长、规则问题。
- `tool_failed`：工具或模型故障后无法继续。

`model_mode` 单独标识 `live` 或 `mock`。Mock 仅验证流程，不证明真实模型决策。

## 验收标准

正常生成、缺关键信息、无素材、工具失败、超时长后修正或明确失败均有可执行测试与实际记录。至少三组输入、输出与 Trace 覆盖全部验收点；至少两条真实模型路径体现工具结果改变后续动作。Trace 记录步骤、工具参数、返回摘要、后续动作及简短依据。模型每次观察工具结果后自行选择动作，固定分支不冒充 ReAct。所有产品事实须对应合成素材原文；无依据效果断言不可作为已通过结果。达到调用上限时明确返回未完成。
