本项目的需求整理、技术方案、代码初版、测试与文档由 Codex 在用户指导下辅助完成。用户明确选择了题目 4、LangGraph、HTTP API、千问预留接口、FastAPI，并要求逐模块实现和检查。Codex 编写并运行了模块测试，根据失败测试调整了规则风险用例，再生成实际 Mock HTTP 示例。
