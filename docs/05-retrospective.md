# 复盘

最难的问题是兼顾模型自主选择下一动作与可验证的完成边界。因此图只路由模型动作，代码门禁只判定当前脚本是否有有效素材、时长和规则检查。草稿版本号阻止旧检查结果用于新脚本。

一次测试发现：30 秒的 Mock 风险用例会先因超时长压缩文案，顺带删除风险句，无法验证“规则检查失败后修正”。已将该用例目标设为 40 秒，使规则检查先发现问题，再观察修正与复检。这个调整说明测试输入必须真正触发所声称的路径。

真实联调发现三个离线测试无法暴露的问题：模型无完整检索历史时重复空检索；只核对显式 `fact_claims` 时会漏掉无依据的界面操作；纯提示词约束不能保证每次都返回有效 JSON。已分别通过提供近期观察历史、检查未证明操作、启用 JSON 输出模式修复，并重跑两条 live 路径。
